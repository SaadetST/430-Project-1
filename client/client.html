To test the api try:

  • '/' defaults to getIndex
  • '/title' gets all the top titles
  • '/artists' gets all top artists
  • '/links' gets all top years
  • '/searchTitle?title=Alejandro' looks for that specific title and returns the object.
  • '/searchTitle' This tests the 400 error.
  • '/addSong' adds a song based on user input. Run below commands to terminal to get all returns.
    • edits existing: curl -i -X POST -d "title=Alejandro&artist=Lady+Gaaaa" http://localhost:3000/addSong
    • check: curl -i "http://localhost:3000/searchTitle?title=Alejandro"
    • adds new: curl -i -X POST -d "title=Test&artist=MEE" http://localhost:3000/addSong
    • check: curl -i "http://localhost:3000/searchTitle?title=Test"
  • random link will default to 404
