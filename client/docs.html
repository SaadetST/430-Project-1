Documentation Page

Titles

GET /titles, supports both GET and HEAD requests.

Query params: None

Body params: None

Returns: 200 with a JSON array of strings of all song titles listed within the dataset.

Example: /titles returns ["Hey, Soul Sister", "Love The Way You Lie", "TiK ToK", ...]

Search

GET /searchTitle, supports both GET and HEAD requests.

Query params: title (string, required), the full song title to look up, which is not case-sensitive. Show (string, optional), an extra field to include. It can be repeated and accepts year, genre, duration or link.

Body params: None

Returns: 200 with one JSON object that always contains title and artist, plus any fields requested with show. A 400 if title is missing. A 404 if no song matches.

Example: /searchTitle?title=Memories&show=genre returns { "title": "Memories", "artist": "Maroon 5", "genre": "pop" }

Adding

POST /addSong, supports POST requests.

Query params: None

Body params: Accepts in either application/x-www-form-urlencoded or application/json format. Accepts title (string, required), artist (string, required), year (number, optional), genre (string, optional) and duration (number of seconds, optional). Links generate automatically.

Returns: A 201 with a new song as a JSON object. A 204 if a song with that title already exists, it updates it and returns with no body. A 400 if a required param is missing.

Example: Posting title=Test&artist=Me&year=2015 returns 201 with the new song object.

Editing

POST /editSong, supports POST requests.

Query params: None

Body params: Accepts in either application/x-www-form-urlencoded or application/json format. Accepts title (string, required), artist (string, optional), year (number, optional), genre (string, optional) and duration (number of seconds, optional). Any optional param that is left out or empty keeps its previous value.

Returns: A 204 status with no body on success. A 400 if title is missing. A 404 if no song has that title.

Example: Posting title=Memories&year=2010 returns 204.
